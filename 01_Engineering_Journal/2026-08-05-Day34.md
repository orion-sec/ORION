## Lessons Learned

The primary engineering challenge was not algorithm correctness but inconsistent data contracts between pipeline modules.

Several legacy modules expected plain investigation text while newer modules exchanged structured dictionaries.

Introducing compatibility layers preserved backward compatibility while allowing the pipeline to evolve toward richer structured investigation objects.
